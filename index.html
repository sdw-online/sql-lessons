How it works

Three steps per query

Each lesson follows one day of the video course, on the same tables you build in that day's setup script.

  1. 01

    Predict

    Read the query and pick what you think it returns. Committing to an answer first is what makes it stick.

  2. 02

    Run

    Run the real query against a real database in the page. Then edit it and run your own.

  3. 03

    Watch the rows move

    Step through each clause, FROM to LIMIT, and see which rows it keeps, drops and reorders.

Nothing is installed and nothing leaves your browser.The database runs inside the page. What you type stays on your device.

The course uses PostgreSQL; the lessons use SQLite.Every result was checked against the course's documented output. Setup scripts and exercises are in the course materials.
