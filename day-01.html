Introduction to SQL & Databases

Tables, rows, columns and data types, on the employees table you created in Day 1. Predict what each query returns, run it, then watch which rows it touches. Watch the Day 1 video.

The tables are the ones from the Day 1 setup script, running in SQLite inside your browser. The course itself uses PostgreSQL, so a few things display differently: SQLite shows TRUE/FALSE as 1/0 (shown here as t/f, the way psql prints them), drops trailing zeros (shown here with two decimals where the column is NUMERIC), and words its error messages differently. Every result on this page was checked against the documented output when the page was built. Course repo.
