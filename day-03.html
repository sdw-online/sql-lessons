ORDER BY and LIMIT

Sorting, the Top N pattern and pagination, on the 30-row online_orders table from the Day 3 setup. Predict where a row lands, then run it and watch the rows move. Watch the Day 3 video.

The tables are the ones from the Day 3 setup script, running in SQLite inside your browser. The course itself uses PostgreSQL, so a few things display differently: SQLite shows TRUE/FALSE as 1/0 (shown here as t/f, the way psql prints them), drops trailing zeros (shown here with two decimals where the column is NUMERIC), and words its error messages differently. Every result on this page was checked against the documented output when the page was built. Course repo.
