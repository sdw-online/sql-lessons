# Interactive SQL lessons

Brilliant-style companion lessons for the free **30 Day SQL Challenge** on YouTube. Predict what a query returns, run it for real in your browser, then step through each clause and watch the rows move.

| Day | Lesson | Video |
|---|---|---|
| 1 | [Introduction to SQL & Databases](https://sdw-online.github.io/sql-lessons/day-01.html) | [Watch](https://www.youtube.com/watch?v=mFIMPhiO-N0) |
| 2 | [SELECT and WHERE](https://sdw-online.github.io/sql-lessons/day-02.html) | [Watch](https://www.youtube.com/watch?v=-0uVBtXCZ_s) |
| 3 | [ORDER BY and LIMIT](https://sdw-online.github.io/sql-lessons/day-03.html) | [Watch](https://www.youtube.com/watch?v=s86nI9dPZqY) |

Each page is one self-contained HTML file. The SQL engine is [sql.js](https://github.com/sql-js/sql.js) (SQLite compiled to JavaScript), loaded from cdnjs and pinned with a subresource-integrity hash. Nothing is installed and nothing you type leaves your browser.

The course itself uses PostgreSQL. The tables and queries here are the ones from each day's setup script and video, and every result was checked against the course's documented output.

Course materials, setup scripts and exercises: [sdw-online/30-Day-SQL-Challenge](https://github.com/sdw-online/30-Day-SQL-Challenge).
